# Team Roles Workshop Companion

Interactive companion for the 16Personalities team-roles workshop (International Exchange Workshop, Hradec Králové · UEW Wrocław).

- **Students:** open https://lwawrzynek.github.io/team-roles-workshop/ (or scan the QR code), enter name and team number, assign roles in both projects, answer the reflection and press “Send to instructor”.
- **Instructor:** open https://lwawrzynek.github.io/team-roles-workshop/#instructor for the narrated intro, QR code, class overview, conclusions slides and session archive.

Single self-contained `index.html` (EN / PL / CS). Data is stored only in each browser.
